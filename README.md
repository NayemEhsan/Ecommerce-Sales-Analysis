# 🛒 E-commerce Sales Analysis

## 📌 Project Overview

This project focuses on analyzing e-commerce sales data to discover meaningful business insights and understand overall business performance.

Using MySQL and Python, the project explores sales trends, revenue, profit, customer behavior, product performance, payment methods, and product returns.

The goal is to transform raw data into meaningful insights that can support data-driven business decisions.

## 🛠️ Tools & Technologies

- **MySQL** – Data querying and business analysis
- **Python** – Data analysis and manipulation
- **Pandas** – Data cleaning and processing
- **Jupyter Notebook** – Exploratory Data Analysis (EDA)
- **Matplotlib & Seaborn** – Data visualization

## 🎯 Project Objectives

- Calculate total revenue and profit.
- Analyze monthly sales and profit trends.
- Identify top-performing products and customers.
- Compare revenue and profit across product categories.
- Analyze regional sales performance.
- Explore customer purchasing behavior.
- Examine payment methods and order distribution.
- Analyze product returns and return reasons.
- Explore relationships between sales, discounts, and profit.
