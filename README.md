# E-commerce Sales Analysis

## Project Overview
This project focuses on analyzing e-commerce sales data to identify business insights, sales trends, customer behavior, product performance, and return patterns.

## Tools & Technologies
- MySQL
- Python
- Pandas
- Jupyter Notebook
- Microsoft Excel

## Project Objectives
- Analyze total revenue and profit.
- Identify top-performing products and customers.
- Explore monthly sales trends.
- Analyze regional sales performance.
- Examine payment methods and product returns.

## Project Structure
- `Python/` – Data analysis using Python and Pandas.
- `SQL/` – SQL queries for business analysis.
- `Dataset/` – Dataset used for analysis.
- `Screenshots/` – Visual representations of the analysis.
