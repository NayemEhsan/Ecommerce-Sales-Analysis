# E-commerce Sales Analysis

## 📌 Project Overview

This project focuses on analyzing e-commerce sales data to understand business performance and discover meaningful insights from sales data.

Using MySQL and Python, I explored revenue, profit, customer behavior, product performance, sales trends, payment methods, and product returns.

The project aims to demonstrate practical data analysis skills and support data-driven business decision-making.

## 🛠️ Tools & Technologies

- **MySQL** – SQL queries and data analysis
- **Python** – Data analysis and manipulation
- **Pandas** – Data cleaning and processing
- **Jupyter Notebook** – Exploratory Data Analysis (EDA)
- **Matplotlib & Seaborn** – Data visualization

## 🎯 Business Objectives

- Calculate total revenue and profit.
- Analyze monthly revenue and profit trends.
- Identify top-performing products and customers.
- Compare revenue and profit across product categories.
- Analyze regional sales performance.
- Examine payment methods and order distribution.
- Explore sales amount distribution and outliers.
- Analyze discount and profit relationships.
- Investigate product returns and return reasons.
